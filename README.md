# Mahmud Security Lab

**Hands-on security lab: practical work in cloud, network, API and AI security — tested, documented, explained.**

This repository is the working lab of **Ishtiyak Mahmud** ([Mahmud Security Labs](https://mahmudlabs.com)). Every entry here is something I have actually built, tested or broken in my own environment, written up so that anyone can follow what was done, why it matters, and how to fix it.

---

## What you'll find here

Each lab follows the same structure:

1. **The problem** — what is being tested and why it matters.
2. **What I did** — the exact steps, commands and tools used.
3. **What I found** — evidence (screenshots, captures, output).
4. **The fix** — how to remediate it, and how to verify the fix worked.
